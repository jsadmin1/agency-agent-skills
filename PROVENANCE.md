# Provenance and verification

This collection contains original skills by jsadmin1 and reviewed generic
derivatives of that author's local workflows. The original material is MIT
licensed. Third-party tool names describe integrations; those tools, accounts
and services have their own licenses and terms and are not included here.

The exact per-file hashes are in [skills-manifest.json](skills-manifest.json).
No private source inventory, account value, client record, machine-specific
conversation identity or personal transcript is distributed.

`make-no-mistakes` is copied with its existing MIT license from
https://github.com/jsadmin1/make-no-mistakes at commit
`614d87fb944bfb036b3ff146303c2a4ce9264fb2`. Its original repository is unchanged.
Its model-call evaluation runner is not part of this distribution.

Other original skills are exported separately from private live installations.
Do not assume that installing one configures its third-party tools or initializes
a project. Follow each skill's prerequisites and verify actual runtime state.

## Brain-dump preservation — October 16, 2026

The generic brain-dump-preservation skill and its standard-library helper are
original MIT-licensed material. The private Agent OS companion and real user
transcripts are not included. One independent review found raw-data sensitivity,
destination-containment, conflicting-record-ID and chunk-progress defects. One
bounded repair and independent exact-fix verification accepted the repaired
bundle. The maintainer exports those exact three generic files.

Verification used synthetic inputs, including metadata/non-text secret-pattern
cases, path containment, duplicate/conflicting records, corrupt input, Unicode,
raw-byte reconstruction and malformed chunk sizes. It did not measure model
compliance, automatic skill selection or compatibility with every native log
format. Secret detection is heuristic, including known false negatives for some
JSON password fields; retained originals default to owner-only permissions.
Concurrent hostile ancestor-directory changes are outside the tested boundary.
The verifier checks structure and source spans, not semantic completeness or
authentic approval. Use manual sensitivity review and normal one-writer rules.

After the bounded independent review, the maintainer completed the remaining
source/template reads and made two scoped corrections: the Crawl4AI example
passes its token header through stdin rather than process arguments, and the
YouTube related-video rule applies only when the approved workflow requires a
link. The latter is a studio policy, not a universal YouTube requirement. These
final corrections received maintainer checks, not a third independent review.

Third-party vendor skill bundles and commercial copywriting material are not
redistributed here. Instructions may reference external tools and public
documentation; those references do not relicense or bundle the tools themselves.
